HOW IT WORKS
------------
- When someone fills out the contact form on your website
- The form sends an email using your Brevo API key
- The email is sent TO your email address
- The email will include:
  * Sender's name
  * Sender's email (so you can reply)
  * Subject line
  * Full message content
- You can reply directly to the sender's email

SECURITY NOTE
-------------
Your Brevo API key is embedded in the JavaScript file. This is fine for
contact forms, but keep in mind that anyone can view it in the browser's
developer tools. Brevo has rate limits and security features to prevent
abuse. For production sites, consider using a backend server to handle
API calls more securely.
